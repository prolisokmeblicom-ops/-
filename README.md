# Prolisok

CRM для складу та виробництва м'яких меблів.

## Що вміє

- склад матеріалів
- замовлення на дивани
- списання матеріалів у роботу
- друк маршрутних листів
- QR-code для маршрутного листа
- паспорти диванів
- Excel-імпорт
- одна SQLite база без окремого налаштування

## Режими запуску

### 1. Для розробки на одному комп'ютері

```bash
npm install
npm run install:all
npm run dev
```

Адреси:

- frontend: `http://localhost:5173`
- backend: `http://localhost:4000/api`

### 2. Для роботи в офісі по локальній мережі

Це основний рекомендований варіант.

Один комп'ютер працює як головний сервер:

- на ньому лежить проект
- на ньому зберігається база `server/data/warehouse.db`
- інші комп'ютери відкривають сайт у браузері по IP цього комп'ютера

## Як підготувати головний комп'ютер

### Крок 1. Встановити Node.js

Перевірка:

```bash
node -v
npm -v
```

### Крок 2. Встановити залежності

```bash
cd "C:\Users\Владислав\Documents\New project"
npm install
npm run install:all
```

### Крок 3. Запустити офісний режим

```bash
cd "C:\Users\Владислав\Documents\New project"
npm run lan:start
```

Що робить ця команда:

- збирає frontend
- запускає один сервер на `4000`
- сервер сам роздає і сайт, і API

## Як підключити інші комп'ютери

### Крок 1. Дізнатися IP головного комп'ютера

На головному комп'ютері виконай:

```bash
ipconfig
```

Шукай `IPv4 Address`, наприклад:

```text
192.168.0.25
```

### Крок 2. Відкрити сайт з інших ПК

На інших комп'ютерах у браузері відкрий:

```text
http://192.168.0.25:4000
```

Замість `192.168.0.25` підстав свій IP.

## Важливо для Windows

Якщо інші комп'ютери не бачать сайт:

- перевір, що всі комп'ютери в одній локальній мережі
- дозволь `Node.js` у брандмауері Windows
- за потреби відкрий порт `4000`

## Де лежить база

Єдина робоча база:

```text
server/data/warehouse.db
```

Саме цей файл містить усі:

- замовлення
- матеріали
- списання
- паспорти диванів

Рекомендується регулярно копіювати цей файл у резервну папку.

На головному комп'ютері:

http://IP_ГОЛОВНОГО_КОМП'ЮТЕРА:4000
